# Edge AI Benchmark Suite

Power consumption and inference benchmarks comparing two edge platforms running LLM and object detection workloads.

## Platforms

| Folder | Board | Accelerator | Details |
|---|---|---|---|
| [`test_raspberrypihat/`](test_raspberrypihat/README.md) | Raspberry Pi 5 | Hailo AI HAT+ 2 (Hailo H10, 40 TOPS) | Qwen3-1.7B + YOLOv8n 80-class |
| [`test_stm32mp257f/`](test_stm32mp257f/README.md) | STM32MP257F-DK | On-chip NPU | FunctionGemma-270M + YOLOv8n person detection |

## Power measurement

Power consumption is measured with a **FNIRSI FNB-C2** USB meter connected to each board's power input.

The `.CFN` files recorded by the FNIRSI official software (FNIRSI USB METER ON WINDOWS https://www.fnirsi.com/it/pages/software-downloads) are converted to `.CSV` using [usbmeter-utils](https://github.com/didim99/usbmeter-utils). The resulting `.csv` files are included in this folder for them to be plotted.

## Plotting results

```bash
python3 plot.py
```

This produces the comparison graphs and summary tables from the benchmark and power data.

## Benchmark results

The `PI5_PERFORMANCES/` and `ST_PERFORMANCES/` folders contain the `.txt` result files (FPS, tokens/s) generated by the scripts in the corresponding `test_` folders during the continuous execution on edge for the power consumption measurements.
